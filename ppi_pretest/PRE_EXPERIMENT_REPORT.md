## 4. 结论

1. **多模态方向: 成立** — v2 总增益 +0.0562 (n=3), v1 对照 +0.0459; 跨表征版本方向一致, 远超 +0.01 判定线
2. **结构路 (prostt5): 方向性支持** — v2 +0.0254 (2/3 seeds 正); v1 均值池化下 -0.0082 → 池化方式是此前零贡献的主因; 幅度受小样本种子噪声限制, 精确量化留给正式实验
3. **全局路 (text+genome): 稳定正贡献** — v2 +0.0308, v1 +0.0541; 本数据最可靠的增量来源

4. **稳定性: 多模态同时降低种子方差** — test_auprc std 从 R1 的 0.0358 降至 R7 的 0.0116; ACC std 0.0298 → 0.0047 (n=3, 提示性证据)

## 5. 正式实验设计指令

1. 残基路: 逐残基 (256,D) + 掩码注意力池化, **禁止均值池化**; 可升级残基间 cross-attention (N_HEADS=4 已在 configs 预留)
2. 全局路: text+genome 原样保留
3. 数据规模: 全量 163,192 / 59,260 / 52,048 对 (5k 子集种子噪声过大, 见 §6)
4. 训练组件照搬: R-Drop / 标签平滑 / warmup+cosine / bf16 / 早停
5. 工程修整: 统一 04/05 的序列截断与 special-token 约定 (本次观测 Lp−Le∈{0,1}, esm2 上限 255 vs prostt5 256, 疑 off-by-one)
6. 种子 ≥3, 报告 mean±std 与逐 seed 配对差

## 6. 局限

- 5k 训练对下单配置种子波动大 (R1 test_auprc 极差 0.0714)
- val 仅 999 对, 早停选优噪声偏大
- prostt5 掩码含 special tokens (±1 token 级, 无实质影响)
- n=3 seeds, 仅方向一致性, 未做显著性检验
